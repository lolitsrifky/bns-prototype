# BNS Predictive Operations — Frontend Prototype

React + Vite + TypeScript prototype for the BNS Predictive Operations Platform.

## Current scope

- Login page aligned to the Figma design (split hero + form, English / Bahasa)
- Dashboard preview (sidebar, KPIs, revenue chart, attention list, regional table)

## Scripts

```bash
npm install
npm run dev
npm run build
```

Open the local URL printed by Vite (usually `http://localhost:5173`).
